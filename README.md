## Featured Projects

###  [Eduzyra](https://github.com/nitinojha-king/Eduzyra_by_Athexus) — Full-Stack LMS *(Live @ Althexus)*
> React · Node.js · MongoDB · Razorpay · Cloudinary · JWT

Multi-role LMS (Student / Instructor / Admin) with Razorpay payment webhooks, OTP email verification, certificate generation & public verification, coupon system, and in-app notifications. Hardened with Helmet, rate limiting, mongo-sanitize, Zod validation, and Winston logging.

---

###  [Travel Squad](https://github.com/nitinojha-king/Travel-Squad) — Social Travel Platform *(Live)*
> Next.js · Node.js · PostgreSQL · Socket.IO · TypeScript · Leaflet

Discover travel companions, post itineraries, and coordinate via live group chat. Uses Haversine distance queries inside PostgreSQL to find nearby travellers, rendered on an interactive Leaflet map.

---

###  [Ventrest](https://github.com/nitinojha-king/CodeX) — Street Vendor Platform *(Runner-up, Techfest 5.0)*
> Node.js · Express · MongoDB · RBAC

Single backend serving Vendors, Suppliers, and Customers with strict role-based access control — shop management, supplier connectivity, micro-loan access, and government scheme discovery shipped in an 8-hour hackathon window.
